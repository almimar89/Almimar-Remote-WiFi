# Almimar TV IPTV 1.3

Android TV application for user-authorized IPTV streams. Arabic UI, free public IPTV-org playlists, Xtream M3U subscriptions, bookmarks, recent channels, Media3 player. Does not circumvent DRM or decrypt beIN channels. Use beIN/TOD official app for protected content.

Build: Actions > Build Almimar TV APK > artifact Almimar-TV-1.3-APK.
